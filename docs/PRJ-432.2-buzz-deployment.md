# PRJ-432.2 — Buzz deployment (`buzz.weown.tools`)

> #WeOwnVer: v4.3.2.1 · Status: ACTIVE · Ticket: PRJ-432.2

## Summary

Deploy Block's [Buzz](https://github.com/block/buzz) agentic chat / Nostr relay on a
DigitalOcean droplet for `buzz.weown.tools`, with Caddy TLS and Cloudflare DNS in
front. Repo mirror lives under [`buzz-docker/`](../buzz-docker/).

## Decisions

1. **Use upstream `deploy/compose/`, not root `docker-compose.yml`.** Root compose is
   local-dev (Keycloak, Adminer, Prometheus, published DB ports). Production is the
   relay + Postgres + Redis + MinIO + optional Caddy TLS overlay.
2. **Pull image, do not build on the 4 GB droplet.** `ghcr.io/block/buzz:main` avoids
   Rust/Node compile OOM; 4 GB swap is still configured as a safety net.
3. **Secrets generated on host only.** `buzz-docker/scripts/bootstrap-host-env.sh`
   writes `.env` (`0600`) and `/root/buzz-owner-keypair.txt`. Agents must not `cat`
   those files (AGENTS.md S1).
4. **Caddy in Compose (not host package)** via `BUZZ_COMPOSE_TLS=true` /
   `compose.caddy.yml`, matching Block's documented VPS path.
5. **Cloudflare orange-cloud OK.** HTTP-01 ACME succeeded through the proxy; set SSL
   mode to Full (strict).

## Execution checklist

### 1. Host preparation

```bash
ssh root@<DROPLET_PUBLIC_IP>
# Docker CE + compose plugin, git, ufw 22/80/443
# 4G /swapfile + fstab
mkdir -p /opt/buzz-weown-tools
```

### 2. Source + config

```bash
git clone --depth 1 https://github.com/block/buzz.git /opt/buzz-weown-tools/buzz
cd /opt/buzz-weown-tools/buzz/deploy/compose
BUZZ_DOMAIN=buzz.weown.tools /path/to/bootstrap-host-env.sh "$(pwd)"
```

### 3. SSL + start

```bash
BUZZ_COMPOSE_TLS=true ./run.sh start
```

Caddy obtains Let's Encrypt for `buzz.weown.tools` and reverse-proxies to `relay:3000`.

### 4. DNS / Cloudflare

- Proxied `A` → `<DROPLET_PUBLIC_IP>`
- SSL/TLS: Full (strict)
- Confirm ACME challenge hits origin `:80` (UFW allow)

### 5. Verification

```bash
BUZZ_COMPOSE_TLS=true ./run.sh status
docker ps   # relay/postgres/redis/minio healthy; caddy up
curl -fsS -o /dev/null -w '%{http_code}\n' https://buzz.weown.tools/          # expect 200
curl -fsS -o /dev/null -w '%{http_code}\n' https://buzz.weown.tools/_liveness # expect 200
```

## Owner access (human-only)

```bash
# On your machine — do not pipe into an agent session
ssh root@<DROPLET_PUBLIC_IP> 'cat /root/buzz-owner-keypair.txt'
# Import RELAY_OWNER_PRIVATE_KEY into Buzz desktop; point relay at wss://buzz.weown.tools
```

Public owner pubkey is also at `/opt/buzz-weown-tools/OWNER_PUBKEY.txt`.

## Membership

Closed relay (`BUZZ_REQUIRE_RELAY_MEMBERSHIP=true`). Add members:

```bash
cd /opt/buzz-weown-tools/buzz/deploy/compose
./run.sh add-member <64_HEX> --role member   # or --role admin
# sleep 1 between adds if looping
```

## Backup

```bash
./run.sh backup-hint
```

Back up `.env`, owner keypair, Postgres, MinIO, `buzz-git-data`, and Caddy volumes
from the same maintenance window.
